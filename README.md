# Late Night with PieroLiero

PieroLiero’s retro television homepage, with music, vlogs, Instagram, Kick, events, and the joke store.

## Hosting

GitHub Pages serves `index.html` from the repository root. The site uses plain HTML, CSS, and JavaScript; no build step is required.

## Content

- Vlogs: 29 saved YouTube entries in `vlogs.js`.
- Instagram: 12 saved profile posts in `instagram-grid.js`, including the three pinned posts first.
- Store: original product content in `store-data.js`; product links lead to the existing Squarespace store.
- Music: Spotify is marked coming soon.
- Bookings: `pierolieromgmt@gmail.com`.
- Kick: links to the channel and replay archive. Live replay fetching requires the optional local preview server; GitHub Pages falls back to direct Kick links.

Saved feeds are snapshots, not automatically synchronized. Update the data files to refresh them.

## Artwork

The TV, vinyl, Polaroid frame, and collage background were created with Higgsfield Nano Banana Pro. PieroLiero and Bad Decisions logos and supplied photographs are the owner’s brand assets. The collage includes the owner’s supplied reel screenshots. The original Professor’s Office and Hotel prototypes remain in the local workspace, separate from this deployment.
